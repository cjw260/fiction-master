## 已修复问题

| 优先级 | 问题与触发条件 | 修复 |
|---|---|---|
| P1 | 图谱查询与主检索并行时，主检索在进入清理区前失败或取消，会遗留图谱任务与未取回的异常。 | 将主检索纳入 `try/finally`，无论成功、失败或取消都回收图谱任务。 |
| P2 | 图谱超时只限制单次 HTTP 请求，多次重试与退避可能超过用户配置的查询时限。 | 从任务启动起限制整个查询的总时长，超时回退到主检索。 |
| P2 | 现有数据库中有 `paused` 图谱，但普通同步和调度器未将暂停视为应保留的状态，会再次启动建图。 | 同步、调度与待建判断均保留暂停版本；显式重建生成的新版本仍可建图。 |

同时修复两处格式检查失败，更新数据发布说明，并将备份目录排除在 Docker 构建上下文外。
